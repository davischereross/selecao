# 🇧🇷 Seleção Brasileira 2026

## 📌 Sobre o projeto

Este projeto consiste em um site desenvolvido sobre a Seleção Brasileira de Futebol, com informações sobre os jogadores convocados, a agenda de jogos da Copa do Mundo de 2026 e a história das conquistas do Brasil em Copas do Mundo.

O site foi desenvolvido utilizando HTML, CSS e JavaScript, com o objetivo de praticar a criação de páginas web, organização de arquivos, estilização, interação com elementos da página e navegação entre diferentes páginas.

---

## 📂 Estrutura do projeto

O projeto está organizado da seguinte maneira:

### 📄 `index.html`

É a página principal do site.

Ela apresenta as principais informações sobre a Seleção Brasileira, incluindo:

- 🇧🇷 Identidade visual da Seleção;
- Convocados para a Copa do Mundo de 2026;
- Fotos dos jogadores;
- Informações sobre os jogadores;
- Agenda dos jogos da fase de grupos;
- Imagens relacionadas à Seleção;
- Links para redes sociais;
- Botão para acessar a página sobre as Copas do Mundo conquistadas pelo Brasil.

O arquivo HTML é responsável principalmente pela **estrutura e organização do conteúdo da página**.

---

### 🎨 `style.css`

É o arquivo responsável pela aparência do site.

Nele foram definidos elementos como:

- Cores;
- Tamanhos de textos;
- Fontes;
- Espaçamentos;
- Posicionamento dos elementos;
- Cards dos jogadores;
- Tamanho das imagens;
- Botões;
- Menu de navegação;
- Organização das seções;
- Responsividade da página.

O CSS permite deixar o site mais organizado, bonito e fácil de visualizar.

---

### ⚙️ `script.js`

É o arquivo responsável pelas interações do site utilizando JavaScript.

Ele pode ser utilizado para adicionar funcionalidades e eventos à página, como:

- Cliques em botões;
- Interações com elementos;
- Alteração de informações;
- Eventos do mouse;
- Eventos de teclado;
- Manipulação dos elementos HTML.

O JavaScript torna o site mais interativo e permite que ações realizadas pelo usuário tenham respostas na página.

---

### 📄 `hexa.html`

É uma segunda página do projeto, acessada através do site principal.

Essa página apresenta a história das **cinco Copas do Mundo conquistadas pela Seleção Brasileira**:

- 🏆 1958 — Suécia
- 🏆 1962 — Chile
- 🏆 1970 — México
- 🏆 1994 — Estados Unidos
- 🏆 2002 — Coreia do Sul e Japão

A página foi criada para complementar o site principal, apresentando a história das conquistas brasileiras em Copas do Mundo.

---

### 🖼️ Pasta `img`

A pasta `img` é utilizada para armazenar as imagens utilizadas no projeto.

Separar as imagens em uma pasta facilita a organização dos arquivos e permite que elas sejam utilizadas nas páginas HTML através dos caminhos dos arquivos.
